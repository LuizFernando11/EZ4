# EZ4 — versão independente

Esta pasta contém uma reimplementação independente em HTML/CSS/JS do site público do EZ4.

## Arquivos
- index.html — estrutura e conteúdo
- style.css — visual responsivo
- script.js — menu mobile, roster e interações
- assets/ — pasta reservada para uma cópia local dos assets

## Rodar
Abra `index.html` no navegador.

## Observação sobre fidelidade
A estrutura, textos, seções e referências visuais foram reconstruídos a partir da versão pública disponível em:
https://ez4-clan.rerra3316.chatgpt.site/

As imagens atualmente apontam para os assets públicos do site original. Para uma cópia 100% offline, salve os PNGs na pasta `assets/` e troque os `src` no HTML para os arquivos locais.
